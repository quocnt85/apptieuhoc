# Parent Persona: Minh (Age 35, Working Parent)

## Purpose
Defines the parent user demographic, values, privacy expectations, and feature requirements for the Parent Companion Portal.

## Profile Summary
- **Age:** 35 years old (Father of an 8-year-old child)
- **Occupation:** Office Professional
- **Primary Need:** Wants their child to learn practical life skills (money management, emotional resilience) without resorting to screen addiction or passive video watching.

## Key Feature Requirements
1. **Real-Time Mastery Digest**: Weekly push notification summarizing skill progress in plain language (e.g. "Leo mastered saving goals this week!").
2. **Offline Conversation Starters**: 1-minute daily dinner table discussion prompts related to current lesson topics.
3. **Screen Time Guardrails**: Configurable daily play limits (e.g. max 20 mins/day).
