# 📁 THƯ MỤC LƯU TRỮ CÁC FILE GỐC CŨ TẠI ROOT (Legacy Root Files Archive)

Thư mục này lưu trữ các file Markdown, YAML và script nháp cũ từng nằm ở root repo trước khi được dọn dẹp và chuẩn hóa:

| File Lưu Trữ | Nguồn Gốc & Lý Do Lưu Trữ | Nơi Đã Được Thay Thế Chính Thức |
| :--- | :--- | :--- |
| `WIKI.md` | Bản tóm tắt 10 module V1 cũ (viết ngày 31/07/2026). | Thay thế bởi `docs/PRD_V1/` và `wiki/INDEX.md` |
| `SUMMARY.md` | Mục lục markdown chứa các link macOS cũ (`file:///Users/thuy/...`). | Thay thế bởi `docs/PRD_V2/01_PRODUCT_VISION_AND_PERSONAS.md` |
| `SYSTEM.md` | Khai báo YAML 12 domain cũ của NovaStars OS V2. | Thay thế bởi `docs/PRD_V2/01_PRODUCT_VISION_AND_PERSONAS.md` |
| `scratch_test.js` | File JS nháp chứa chuỗi text copy-paste của Universal Framework. | Thay thế bởi `docs/PRD_V1/02_V1_UNIVERSAL_COMPETENCY_FRAMEWORK_AND_SCHEMA.md` |
| `PROJECT CHARTER.docx`| Bản thảo Word ban đầu của Dự án. | Thay thế bởi `docs/PRD_V1/01_V1_PROJECT_CHARTER_AND_PRODUCT_FOUNDATION.md` |
