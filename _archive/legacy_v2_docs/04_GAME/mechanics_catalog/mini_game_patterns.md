# Game Mechanics Catalog: Reusable Mini-Game Interaction Patterns

## Purpose
Catalog of reusable interactive mini-game mechanics and UI puzzle patterns used across Stage 2 Exploration and Stage 3 Boss Challenges.

## Pattern Catalog

### 1. The Balance Scale (`MCH-PAT-001`)
- **Interaction:** Drag items onto a physical scale to balance budget vs. expenses or pros vs. cons.
- **Pedagogical Target:** Financial budgeting (`SUB-FIN-BUDG`), trade-off evaluation (`SUB-CRT-RISK`).

### 2. Scenario Branching Matrix (`MCH-PAT-002`)
- **Interaction:** Interactive comic strip where choosing a dialogue choice dynamically updates the NPC's emotional state icon.
- **Pedagogical Target:** Emotional regulation (`SUB-SEL-REGU`), healthy communication (`SUB-SEL-COMM`).

### 3. Sorting Bucket Challenge (`MCH-PAT-003`)
- **Interaction:** Categorize falling or floating items into correct target buckets (e.g. Needs vs. Wants, Fact vs. Opinion).
- **Pedagogical Target:** Distinguishing Needs vs. Wants (`SUB-FIN-NEED`), Information evaluation (`SUB-CRT-INFO`).

### 4. Sequence Builder (`MCH-PAT-004`)
- **Interaction:** Arrange 3-5 action cards in logical chronological order to solve a problem.
- **Pedagogical Target:** Time management (`SUB-HAB-TIME`), logical reasoning (`SUB-CRT-LOGIC`).
